# FreeDeshadow Project Page

Project page for:

**FreeDeshadow: Shadow Removal for User-Specified Objects With Multimodal Prompts**

Zhiliang Wu, Jihao Gu, Kun Li, Hanyu Xuan, Hehe Fan, Meng Wang, Weisi Lin

The page is adapted from the Nerfies GitHub Pages template and includes:

- teaser and abstract;
- framework overview (object-aware generator + shadow-aware local refiner);
- PCSRD+ dataset construction pipeline and statistics;
- visual results (six prompt types, comparisons with image editing and shadow removal methods, real images, multi-object, zero-shot, controllability);
- conclusion and BibTeX.
